# Rust → системный инженер: карта курса

Пошаговый курс без интернета: от первой строчки кода до системного инженера, на Rust.
Все объяснения — внутри уроков; ссылки на официальные источники — в конце каждого
урока. **Вы здесь впервые? Откройте [Начните здесь](START-HERE.md).**

## Стадии

1. **Фундамент: инструменты, Git и язык Rust** — этапы 00–06
2. **Основы инженерии** — этапы 07–11
3. **Как на самом деле работают компьютеры** — этапы 12–14
4. **Построить настоящие системы** — этапы 15–18
5. **Мастерство и карьера** — этапы 19–24

## Структура папок

```
rust/                    ← ваш репозиторий (~/projects/rust)
├── README.md            ← ваша страница: кто вы, ваша цель, ваш прогресс
├── code/                ← ваш код (создаёте вы): code/pNN-<имя>
├── notes/               ← ваши заметки (создаёте вы)
└── course/
    ├── en/              ← этот курс на английском
    └── ru/              ← этот курс на русском
        ├── START-HERE.md    ← начните здесь
        ├── README.md        ← эта карта курса
        ├── PROGRESS.md      ← отмечайте пройденные уроки
        ├── GLOSSARY.md      ← все сокращения и термины с объяснениями
        └── 00-…/ … 24-…/    ← уроки: одна папка на этап
```
