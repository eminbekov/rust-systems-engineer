# Rust → Systems Engineer: course map

An offline, step-by-step course from your first line of code to systems engineer, in Rust.
All explanations are inside the lessons; links to the official sources are at the end of
each lesson. **New here? Open [Start here](START-HERE.md).**

## Stages

1. **Foundations: tools, Git and the Rust language** — phases 00–06
2. **Engineering fundamentals** — phases 07–11
3. **How computers really work** — phases 12–14
4. **Build real systems** — phases 15–18
5. **Mastery and career** — phases 19–24

## Folder layout

```
rust/                    ← your repository (~/projects/rust)
├── README.md            ← your own page: who you are, your goal, your progress
├── code/                ← your code (you create it): code/pNN-<name>
├── notes/               ← your study notes (you create it)
└── course/
    ├── en/              ← this course in English
    │   ├── START-HERE.md    ← begin here
    │   ├── README.md        ← this course map
    │   ├── PROGRESS.md      ← tick lessons as you finish them
    │   ├── GLOSSARY.md      ← every abbreviation and term, explained
    │   └── 00-…/ … 24-…/    ← the lessons: one folder per phase
    └── ru/              ← the same course in Russian
```
