# Phase 00 — Getting started

> **Stage 1 — Foundations: tools, Git and the Rust language** · ⏱ about 1–2 weeks at ~10 hours per week

## What this phase is about

Before you write real programs, you need to understand three things: what a program is, how a
computer runs it, and how you will talk to the computer. This phase teaches exactly that, from
zero. You learn what programming means, what the processor, memory and operating system do when
you start a program, and why a compiler is needed.

Then you get your hands on the tools. You learn the **terminal** (the text window in which
programmers work), install **Rust** and the **RustRover** IDE (the program in which you write code), and write, run and
change your first Rust program with **Cargo**. You also check that **Git** is installed, because
the very next phase teaches version control: the tool that remembers every version of your files and
protects your work. Cargo even creates a small Git repository for you, and you will see it here.

The second half of this phase is about habits. You learn to **read compiler errors calmly** (the most important
skill for a beginner in Rust), to look for answers in the right order, and to ask good questions. You
build a weekly study routine, a learning journal, notes in Markdown and a three-layer safety net for your work
(version control, a backup and a remote copy). The phase ends with a checkpoint that shows
whether you are ready for Phase 01.

## What you will be able to do

- [ ] Explain in simple words what a program, an algorithm and a compiler are, and how a computer runs a program (CPU, RAM, storage, operating system).
- [ ] Read binary numbers and explain bits, bytes and machine code.
- [ ] Work in the terminal: move around folders, create, copy, move and delete files, use pipes, `PATH` and permissions.
- [ ] Install and check the Rust toolchain (`rustup`, `rustc`, Cargo) and set up RustRover with `rustfmt` and Clippy.
- [ ] Create, build, run, format and lint a Rust project with Cargo, and explain every file Cargo creates.
- [ ] Read a compiler error, fix many errors one at a time, use `rustc --explain` and the offline documentation, and write a good question.
- [ ] Keep a learning journal and notes in Markdown, and protect your work with Git, a backup and a remote copy.

## Projects in this phase

There is no big project in Phase 00. You create small programs and files in your own folders:

- `code/p00-hello` — your first Cargo project (Lesson 00.6).
- `code/p00-banner` and `code/p00-table` — small exercises that print a box and a times table (Lesson 00.6).
- `code/p00-checkpoint` — the study card program of the checkpoint (Lesson 00.8).
- `notes/phase-00.md` and `notes/phase-00-report.md` — your first journal and a toolchain report in Markdown (Lesson 00.8).

## How to study this phase

- Do the lessons in order. Each one uses tools that the previous one installed.
- Open the terminal next to the lesson and **type every command yourself**. Compare your output with the lesson.
- In Lessons 00.4 and 00.6, make mistakes on purpose (a wrong path, a missing `;`) and read the messages: this is training for Lesson 00.7.
- Keep your learning journal from the first day: five lines after every lesson, and a review after 1, 3, 7 and 30 days.
- Finish with the checkpoint in Lesson 00.8. If you answer at least 15 of 18 questions and do the practical tasks, start Phase 01.
