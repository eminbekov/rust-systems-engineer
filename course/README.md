# Rust → Systems Engineer · the course

A complete, step-by-step course that takes a complete beginner from the first line of code to
working as a systems engineer, in Rust. 353 lessons in 25 phases, in English and Russian.

## What makes it different

- **Offline and complete.** Every idea is explained inside the lesson, in simple words, for someone
  who has never programmed. Links to the official sources come at the end, for going deeper.
- **Every abbreviation is expanded** the first time it appears, and the glossary explains about
  2,700 terms in both languages.
- **Real output.** Code examples are complete programs, and the outputs and error messages shown
  in the lessons come from running them (Rust 1.100, edition 2024). Output that cannot be run on a
  normal Mac (a virtual machine, a microcontroller board, a CI service) is labelled as an example.
- **Practice everywhere.** Each lesson has a guided "Try it yourself", graded exercises with hidden
  hints and answers, and a quiz. Phases end with a project (a contract, milestones and acceptance
  tests, no ready-made solution) and a checkpoint.
- **Engineering habits from day one:** Git, tests, benchmarks, security and design conventions are
  woven into the lessons, not left for the end.
- **Follow the links.** Every page has Start · Previous · Phase · Next · Glossary links, so you
  can study the files in order like a book.

## The stages

| Stage | Phases | Time at ~10 h/week |
|---|---|---|
| 1. Foundations: tools, Git and the Rust language | 00–06 | about 5–6 months |
| 2. Engineering fundamentals | 07–11 | about 5 months |
| 3. How computers really work | 12–14 | about 3 months |
| 4. Build real systems | 15–18 | about 4–5 months |
| 5. Mastery and career | 19–24 | about 6 months |

## What you need

A computer (the lessons are written for macOS on Apple Silicon; Linux works for almost
everything), about 10 hours per week, and the internet only for installing tools and libraries.
